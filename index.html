01 // Hardware Interface Specification

Every metric and control maps directly to an OS power interface, WMI/CIM namespace, or NVIDIA driver API.

Subsystem Native Interface / GUID Behavior on Locked OEM Laptops
Maximum Processor State SUB_PROCESSOR / PROCTHROTTLEMAX (bc5038f7-23e0-4960-96da-33abaf5935ec) Fully active (50%–100% slider applied live to AC & DC).
Processor Boost Mode SUB_PROCESSOR / PERFBOOSTMODE (be337238-0d82-4146-a960-4f3749d470c7) Switches between 0 Disabled, 3 Efficient Enabled, 2 Aggressive.
System Cooling Policy SUB_PROCESSOR / SYSCOOLPOL (94d3a615-a899-4ac5-ae2b-e4d8f634367f) Switches OS fan-ramp preference between 0 Passive and 1 Active.
CPU Temp & Turbo Clock MSAcpi_ThermalZoneTemperature, ThermalZoneInformation, ProcessorInformation, optional LHM WMI Falls back across real CIM counters; reports N/A (Sensor Locked) if firmware omits zones.
GPU Telemetry & PWM nvidia-smi CSV + direct nvml.dll fan control probe Unlocks manual/curve PWM on supported desktop GPUs; shows Locked by OEM BIOS EC and N/A (OEM EC Locked) on EC-locked laptops.
Thermal Load Verification Multi-process floating-point ALU burn (multiprocessing.Process) Runs at 25% / 50% / 75% / 100% logical threads to test real cooling ramp & temp delta.

02 // Deployment & Execution

Choose the portable Python launcher (recommended on Windows 11 Smart App Control systems) or the standalone PyInstaller executable.

PORTABLE SETUP (RECOMMENDED)

SMART APP CONTROL IMMUNE
  1. Download HANKO_Portable_Setup.zip from Releases and extract it.
  2. Double-click setup_and_run.bat.
  3. Accept the Administrator UAC prompt (required for powercfg).
  4. Missing packages (customtkinter, psutil, pillow) install automatically and a HANKO Thermal Suite Desktop shortcut with the Victus V icon is created.
git clone https://github.com/hankobanko391/HANKO-Thermal-Suite.git cd HANKO-Thermal-Suite .\setup_and_run.bat

STANDALONE EXECUTABLE

NO PYTHON REQUIRED
  1. Download HANKO_Thermal_Suite.exe from Release v1.0.0.
  2. Run the binary (built with --onefile --windowed --uac-admin).
  3. If Windows Smart App Control blocks unsigned executables on your PC, switch to HANKO_Portable_Setup.zip.
pyinstaller --noconfirm --clean --onefile --windowed --uac-admin ^ --collect-all customtkinter --name HANKO_Thermal_Suite ^ --icon assets\hanko_victus.ico main.py
