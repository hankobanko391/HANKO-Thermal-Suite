01 // Hardware Interface Specification

Every readout and tuning lever maps directly to PawnIO LibreHardwareMonitor, NVIDIA SMI, Windows powercfg, or CIM/WMI.

Subsystem Native Interface / Library Behavior & OEM EC Fallback
Multi-Fan Telemetry Array fan_engine.py → LibreHardwareMonitorLib.dll (PawnIO) via pythonnet Scans Motherboard, SuperIO, EC, Controller, and GPU SensorType.Fan channels; displays DETECTED FANS: N with RPM + % load bars, or EC TELEMETRY LOCKED BY HP BIOS if firmware blocks readouts.
GPU Core Clock Lock (MHz) clock_tuner.py → nvidia-smi --lock-gpu-clocks / --reset-gpu-clocks Locks RTX 2050 / NVIDIA GPU clock across 800–1850 MHz (step 15 MHz) silently via CREATE_NO_WINDOW, or restores stock VBIOS scaling.
CPU Max Frequency (GHz) clock_tuner.py → powercfg SUB_PROCESSOR PROCFREQMAX Converts 1.80–4.50 GHz (step 0.10 GHz) to integer MHz across AC+DC on SCHEME_CURRENT; resets to 0 for Turbo Auto.
Thermal & Boost Policies PROCTHROTTLEMAX, PERFBOOSTMODE, SYSCOOLPOL Live AC+DC slider (50%–100%), boost mode toggles (Disabled / Efficient / Aggressive), and Active/Passive cooling switch.
CPU Temp & Live Clocks MSAcpi_ThermalZoneTemperature, ThermalZoneInformation, ProcessorInformation Tracks live Turbo frequency via % Processor Performance and falls back honestly to N/A (Locked) if ACPI zones are disabled.
Thermal Load Verification Multi-process floating-point ALU burn (stress_worker.py) Runs across 25% / 50% / 75% / 100% logical threads to verify clock stability, cooling ramp, and temperature delta.

02 // Deployment & Execution

Bundled with PawnIO-compatible LibreHardwareMonitorLib.dll for Windows 10 and Windows 11.

PORTABLE SETUP (RECOMMENDED)

SMART APP CONTROL IMMUNE
  1. Download HANKO_Portable_Setup.zip from the latest GitHub Release and extract it.
  2. Double-click setup_and_run.bat.
  3. Accept the Administrator UAC prompt (required for powercfg, nvidia-smi clock locks, and hardware sensors).
  4. Dependencies (customtkinter, psutil, pillow, pythonnet) install automatically and a Desktop shortcut is created.
git clone https://github.com/hankobanko391/HANKO-Thermal-Suite.git cd HANKO-Thermal-Suite .\setup_and_run.bat

STANDALONE EXECUTABLE

NO PYTHON REQUIRED
  1. Download HANKO_Thermal_Suite.exe from Release v2.0.0.
  2. Launch the executable (manifest enforces --uac-admin and bundles LibreHardwareMonitorLib.dll).
  3. If Windows Smart App Control blocks unsigned executables on your system, use HANKO_Portable_Setup.zip.
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_release.ps1
